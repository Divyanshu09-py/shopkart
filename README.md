# ShopKart - Full Stack E-Commerce Project

## Step 1
This first step creates the project structure and a basic frontend/backend.

### Frontend
Open:
frontend/index.html

### Backend
Open the terminal inside the backend folder and run:

npm install
node server.js

Then open:
http://localhost:5000

The next steps will add:
- Products
- MySQL database
- REST APIs
- Login/Register
- Cart
- Orders
- Admin panel
